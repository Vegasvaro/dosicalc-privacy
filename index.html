Política de Privacidad – Dosicalc

Última actualización: 10 de mayo de 2026

Esta Política de Privacidad describe cómo la aplicación Dosicalc recopila, utiliza y protege la información de los usuarios.

1. Información que recopilamos

La aplicación Dosicalc no solicita ni requiere que el usuario introduzca datos personales.

Sin embargo, pueden recopilarse automáticamente ciertos datos técnicos a través de servicios de terceros utilizados en la app:

  • Datos del dispositivo: tipo de dispositivo, sistema operativo, idioma, etc.
  • Identificadores publicitarios: como el ID de publicidad del dispositivo (GAID en Android o IDFA en iOS)
  • Datos de uso básicos relacionados con la visualización de anuncios

2. Uso de la información

La información recopilada se utiliza exclusivamente para:

  • Mostrar anuncios dentro de la aplicación
  • Mejorar la experiencia publicitaria
  • Garantizar el correcto funcionamiento de los anuncios

3. Publicidad

La aplicación utiliza el servicio de publicidad Google AdMob, proporcionado por Google LLC.

AdMob puede recopilar y procesar datos, incluyendo identificadores publicitarios, dirección IP y datos de interacción, para mostrar anuncios personalizados o no personalizados.

Política de privacidad de Google:
https://policies.google.com/privacy

4. Consentimiento del usuario (EEE y Reino Unido)

Para usuarios ubicados en el Espacio Económico Europeo (EEE) y Reino Unido, se solicitará el consentimiento antes de utilizar datos para publicidad personalizada, conforme al Reglamento General de Protección de Datos (RGPD).

El usuario puede aceptar o rechazar el uso de anuncios personalizados en cualquier momento desde la configuración de la aplicación o a través de los controles de privacidad del sistema operativo.

5. Compartición de datos

No se venden ni comparten datos personales directamente.

No obstante, ciertos datos pueden ser procesados por terceros como Google AdMob para la prestación de servicios publicitarios, conforme a sus propias políticas de privacidad.

6. Seguridad de los datos

Se adoptan medidas razonables para proteger la información del usuario. Sin embargo, ningún sistema de transmisión o almacenamiento electrónico es completamente seguro, por lo que no se puede garantizar una seguridad absoluta.

7. Derechos del usuario

Dependiendo de la ubicación del usuario, este puede tener derecho a:

  • Acceder a los datos que puedan haberse recopilado
  • Solicitar la eliminación de dichos datos
  • Retirar el consentimiento en cualquier momento
